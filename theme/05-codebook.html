5  The corpus codebook

NoteStatus: generated artefact

The codebook is generated from the derivation registry (Scripts/derivations.yaml) and the dataset itself by Scripts/codebook.py, which writes data/codebook.html. It documents every column of corpus_derived – its pipeline stage, the function that builds it, a description, fill rate and an example value – so provenance and documentation live in one place and cannot drift from the data.

corpus_derived.parquet is the analysis dataset (one row per unique work). Its columns fall into a small number of families: the identity and membership fields and the derived classification come from the assemble and derive stages and are documented one by one in the registry; the bulk of the width is the raw source metadata carried verbatim from each source (OA_*, Scopus_*, WoS_*), auto-documented by the codebook generator. The table below summarises the families; the full column-by-column codebook follows.

Code 
library(arrow); library(dplyr); library(tinytable)
options(tinytable_tt_theme = function(x) {
  x |> theme_tinytable() |> style_tt(align = "l") |>
    style_tt(fontsize = 0.9) |> style_tt(i = 0, fontsize = 0.95, bold = TRUE)
})
nm <- open_dataset("data/final/corpus_derived.parquet")$schema$names
fam <- dplyr::case_when(
  startsWith(nm, "OA_")     ~ "OpenAlex (raw source)",
  startsWith(nm, "Scopus_") ~ "Scopus (raw source)",
  startsWith(nm, "WoS_")    ~ "Web of Science (raw source)",
  grepl("^trust_|^sense_|scope_conflict", nm) ~ "Derived: trust classification",
  grepl("^in_|backfill|^n_sources|^sources|oa_source_type", nm) ~ "Membership + backfill provenance",
  grepl("abstract", nm) ~ "Abstract (resolved + flags)",
  TRUE ~ "Identity / year / document type / content")
tibble(Family = fam, n = 1L) |>
  count(Family, name = "Columns", wt = n) |>
  arrange(desc(Columns)) |>
  tt() |>
  format_tt(j = "Columns", digits = 0)
